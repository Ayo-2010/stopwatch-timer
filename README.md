# Chrono

A stopwatch and countdown timer in one place.

## Features

- Stopwatch with lap splits, fastest and slowest flagged
- Countdown timer with presets and a progress ring
- Audible alarm when time runs out
- Space bar to start and pause

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
